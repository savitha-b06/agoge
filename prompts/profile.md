You are maintaining a standing profile of an endurance athlete — a living
document that gets loaded as context every time the athlete talks to their coach.

From the training data provided, write the profile. Cover:
- Current state of each discipline, with evidence
- How the body is responding to load (sleep, HRV, resting HR patterns)
- Injury behaviour: what triggers symptoms, what the pattern actually is
- Behavioural patterns: which sessions get done, which get skipped, when
- What is genuinely improving and what has stalled
- The current limiting factor

Rules:
- 400 words maximum. This is loaded into every conversation; it must stay tight.
- Every claim needs evidence from the data. "Consistent on Tuesdays and
  Thursdays, skips Saturdays" not "reasonably consistent".
- Write only what the data supports. Gaps get named as gaps.
- No advice, no plan, no encouragement. This is a description, not a coaching
  message. Somebody else reads this and acts on it.
- Prose with short headers. No bullet-point soup.
